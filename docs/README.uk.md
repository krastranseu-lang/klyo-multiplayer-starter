# Чотири в ряд: онлайн-гра для кількох гравців у браузері без власного сервера

Повна HTML5-гра для двох гравців онлайн, **без бекенду, без оплати хостингу і без коду підбору гравців**. Кімнати, посилання-запрошення, швидкий матч, черговість ходів і повернення після обриву зв’язку дає набір [klyo games](https://games.klyo.pl/uk/), а сама гра займає близько 150 рядків звичайного JavaScript.

[English](../README.md)

## Навіщо це

На питання «як зробити онлайн-гру в браузері без сервера» зазвичай відповідають списком сервісів: Photon, Epic Online Services, Nakama, PlayFab. Вони дають мережу, але грі все одно потрібні хостинг, екран лобі, посилання-запрошення і місце, де гравці її знайдуть. На klyo games одне завантаження ZIP дає все це одразу.

| Що потрібно | klyo games |
|---|---|
| Хостинг файлів гри | так, власна адреса `g-your-game.klyo.pl` |
| Онлайн-кімнати, швидкий матч, посилання | так, через набір, без вашого сервера |
| Гравців у кімнаті | до 64 у покрокових іграх, до 16 у реальному часі |
| Рекорди і збереження в хмарі | так, `klyo.score` і `klyo.save` |
| Меню, пауза, фінальний екран, 10 мов | так, `klyo-kit.js` |
| Сторінка в Google | так, після схвалення людиною з klyo |
| Публікація через ШІ-асистента | так, через MCP-сервер klyo |
| Ціна | безкоштовно, без ексклюзивності, права залишаються у вас |

## Як працює онлайн у цій грі

```js
var gra = klyoKit.start({
  nazwa: "Four in a Row",
  tryby: ["solo", "hotseat", "online"],
  online: { players: 2, mode: "turns" },
  naStart: function (tryb, dane) { start(tryb, dane); },
  naRuch: function (m) { apply(m.who, m.move); },
});
gra.ruch({ col: 3 }, isLast ? { end: true, result: { winner: myId } } : null);
```

Це весь мережевий шар: `gra.mojaTura()` каже, чий хід, кімната відхиляє хід не в свою чергу, а коли гравець повертається до кімнати, `dane.ruchy` приносить партію до цього моменту. Дивіться [`game.js`](../game.js).

## Опублікуйте за п’ять хвилин

1. Створіть безкоштовний акаунт розробника на [dev.klyo.pl](https://dev.klyo.pl/).
2. Запакуйте цю папку (index.html угорі) і завантажте її або попросіть ШІ-асистента через [MCP-сервер klyo](https://games.klyo.pl/mcp/).
3. Грайте одразу за власною адресою; після перегляду людиною з klyo гра з’являється в каталозі та в Google. Найшвидший шлях від завантаження до каталогу досі тривав 3 хвилини, зазвичай близько 2 годин.

Онлайн-гра працює всередині порталу klyo (лобі належить порталу), тож із другом грайте зі сторінки гри на klyo. Одиночна гра і гра удвох на одному пристрої працюють будь-де.

## Питання розробників

Коли, що перевіряємо, нові версії, експорт із рушіїв, ліміти і гроші: [Як опублікувати браузерну гру](https://games.klyo.pl/uk/publish-browser-game/). Гроші: коли на порталі запрацює реклама Google, розробник отримає 70% чистого доходу від реклами, віднесеного до його гри. Зараз реклама ще не працює, і нічого з реклами не виплачено.
