# Четыре в ряд: онлайн-игра для нескольких игроков в браузере без собственного сервера

Полноценная HTML5-игра для двоих онлайн, **без бэкенда, без оплаты хостинга и без кода подбора игроков**. Комнаты, ссылки-приглашения, быстрый матч, очерёдность ходов и возвращение после обрыва связи даёт набор [klyo games](https://games.klyo.pl/), а сама игра занимает около 150 строк обычного JavaScript.

[English](../README.md)

## Зачем это нужно

На вопрос «как сделать онлайн-игру в браузере без сервера» обычно отвечают списком сервисов: Photon, Epic Online Services, Nakama, PlayFab. Они дают сеть, но игре всё равно нужны хостинг, экран лобби, ссылки-приглашения и место, где её найдут игроки. На klyo games одна загрузка ZIP даёт всё это сразу.

|---|---|
| Хостинг файлов игры | да, собственный адрес `g-your-game.klyo.pl` |
| Онлайн-комнаты, быстрый матч, ссылки | да, через набор, без вашего сервера |
| Игроков в комнате | до 64 в пошаговых играх, до 16 в реальном времени |
| Рекорды и сохранения в облаке | да, `klyo.score` и `klyo.save` |
| Меню, пауза, финальный экран, 10 языков | да, `klyo-kit.js` |

| Цена | бесплатно, без эксклюзивности, права остаются у вас |

## Как работает онлайн в этой игре

```js
var gra = klyoKit.start({
  nazwa: "Four in a Row",
  tryby: ["solo", "hotseat", "online"],
  online: { players: 2, mode: "turns" },
  naStart: function (tryb, dane) { start(tryb, dane); },
  naRuch: function (m) { apply(m.who, m.move); },
});
gra.ruch({ col: 3 }, isLast ? { end: true, result: { winner: myId } } : null);
```

Это весь сетевой слой: `gra.mojaTura()` говорит, чей ход, комната отклоняет ход не в свою очередь, а когда игрок возвращается в комнату, `dane.ruchy` приносит партию до этого момента. Смотрите [`game.js`](../game.js).

## Опубликуйте за пять минут

1. Создайте бесплатный аккаунт разработчика на [dev.klyo.pl](https://dev.klyo.pl/).
2. Упакуйте эту папку (index.html наверху) в ZIP и загрузите её или попросите ИИ-ассистента через [MCP-сервер klyo](https://games.klyo.pl/mcp/).
3. Играйте сразу по собственному адресу; после просмотра человеком из klyo игра появляется в каталоге и в Google. Самый быстрый путь от загрузки до каталога пока занял 3 минуты, обычно около 2 часов.

Онлайн-игра работает внутри портала klyo (лобби принадлежит порталу), поэтому с другом играйте со страницы игры на klyo. Одиночная игра и игра вдвоём на одном устройстве работают везде.
